
# Personal Expense Tracker 💰

A beginner-friendly Python project to record,
manage and analyse personal expenses.

## Features
- Add daily expenses
- View recorded expenses
- Calculate total spending
- Track spending by category
- Store expense records using JSON

## Technologies
- Python
- JSON
- Git & GitHub

## Project Status
🚧 Currently under development.

## Learning Objectives
- Python fundamentals
- Conditional statements
- Loops and functions
- Lists and dictionaries
- File handling
